Universal Compatibility

One Command Aligns Every Agent

Synapse understands the distinct native rule formats of all major coding agents.

Cursor MCP Native

Automatically injects stdio MCP server into .cursor/mcp.json and rule directives into .cursorrules.

Claude Code CLAUDE.md

Generates and maintains root CLAUDE.md instructions and desktop config for seamless Anthropic CLI integration.

Codex & AGY AGENTS.md

Connects with standard AGENTS.md guidelines to ensure autonomous CLI agents read recent project state before action.

Windsurf .windsurfrules

Hooks into Codeium's Windsurf Cascade agent via .windsurfrules with zero manual configuration.

Cline & Roo Code .clinerules

VS Code's leading autonomous coding extensions automatically discover project context through .clinerules.

Local & Private Zero Cloud

All memory lives locally in .synapse/. No proprietary code is ever uploaded to external servers.

Get Started

Up & Running in 60 Seconds

1

Initialize inside your repository

Navigate to any project and run the universal alignment command:

npx synapse-agent init
2

Start the Live TUI Monitor (Optional)

Keep a dedicated terminal split pane open to observe real-time agent activities:

npx synapse watch
3

Code with any agent freely

Prompt Claude Code in your terminal, write frontend in Cursor, or run batch scripts in Codex. Synapse synchronizes decisions and uncommitted diffs automatically.
